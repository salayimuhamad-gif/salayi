## كيف تُستعمل هذه القائمة

1. تُنفَّذ عمود «كيف نتحقق» بندًا بندًا على الموقع الحي، وتُسجَّل النتيجة في `evidence_log.csv` بمعرّف E جديد ولقطة.
2. البند المؤكد ينتقل إلى سجل القضايا بفئة **A** (مع الإشارة إلى تطابق A-code لرفع الثقة). البند المنفي يُغلق هنا بعلامة «نُفي حيًا — التاريخ».
3. كل ما يبقى غير مُختبَر يُذكر صراحة في قسم «نطاق الأدلة» بوصفه غير مُختبَر.
