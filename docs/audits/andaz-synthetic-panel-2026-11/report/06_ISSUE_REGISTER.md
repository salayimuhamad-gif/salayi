# 6. سجل القضايا الموحَّد وجدول «أصلِح / بسِّط / احذف / أضِف / حافِظ»

**قاعدة القراءة:** كل بند يحمل مرجع دليل (E-…) وفئته. أعداد الشخصيات المتأثرة هي **نتائج لوحة اصطناعية** من محرّك التقييم (القاعدة R-… في `evidence/impact_rules.json`)، لا أعدادًا بشرية. التسميات بين « » منقولة حرفيًا من الموقع بلغتها الأصلية. كل ما يتعلق بالطبقة البصرية أو التفاعل **غير مرصود** ويُذكر ذلك صراحة في خانة الثقة.

**ترتيب الأولوية:** مهام أساسية محجوبة ← معلومات مضلِّلة ← فشل ثقة ← احتكاك واسع ← تفضيلات تجميلية.
